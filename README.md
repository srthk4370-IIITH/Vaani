# Vaani

A Siri-style voice assistant for any laptop. It runs in your terminal and is powered by [Sarvam AI](https://sarvam.ai).
Speak in any Indian language or Hinglish, and Vaani operates your laptop and replies **out loud in your language**.
If something fails, it tells you why, also out loud and in your language.

For architecture, the Sarvam model/endpoint table and contributor notes, see [HANDBOOK.md](HANDBOOK.md).

## Features

- **Two ways to start it:** say **"Hey Vaani"** (wake word, checked by Sarvam STT; no local AI models), or **hold F9** to talk (push-to-talk)
- Understands 10+ Indian languages and Hinglish (Sarvam `saaras:v4` speech-to-text plus translate)
- Controls your laptop: open apps and URLs, search the web, type, press keys and hotkeys, scroll, set volume, close windows
- Reads your screen with Sarvam vision and reads your clipboard
- Talks back with Bulbul TTS in the language you spoke
- Explains errors aloud. If Sarvam is unreachable it plays a local beep
- Windows, macOS, Linux and WSL

## Quick start

You need Python 3.10+ and a Sarvam API key (`vaani setup` asks for it).

**Windows (PowerShell)**
```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
.\vaani.cmd            # or .\run.ps1
```

**macOS / Linux / WSL**
```bash
chmod +x install.sh && ./install.sh
source .venv/bin/activate && vaani
```

**Manual install**
```bash
python -m venv .venv && . .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -e .            # Windows: pip install -e ".[windows]"
vaani setup
```

## Usage

| Command | What it does |
|---|---|
| `vaani` | Starts the assistant. Say "Hey Vaani" or hold F9, then speak |
| `vaani setup` | Onboarding: API key, mic test, wake-word opt-in, preferences |
| `vaani --text` | Type commands instead of speaking (useful when there is no mic) |
| `vaani doctor` | Checks the API key, Sarvam reachability, mic, audio output and wake-word mode |

### Things to try
- "Hey Vaani, YouTube kholo aur lo-fi music search karo"
- "Notepad kholo aur likho: kal meeting 10 baje"
- "Volume 30 percent kar do"
- "Screen pe kya likha hai, padh ke batao"
- "ಈಗ ಸಮಯ ಎಷ್ಟು?" (What time is it?)
- "Google pe aaj ka weather search karo"

## Privacy (local-first)

These run **on your device**: onboarding, settings, API key storage (`~/.vaani/.env`), voice-activity detection (simple energy
threshold, no AI model), audio recording and playback, and all laptop control.
Only the AI calls go to Sarvam's cloud: speech-to-text, translation, text-to-speech, the agent LLM, and vision (screen reading,
which happens only when you ask). Your key is never committed. `.env` files are git-ignored.

**Wake word and privacy:** Vaani runs no local AI models. With the wake word on, a local energy detector notices when
someone speaks, and each spoken phrase is sent to Sarvam STT (`saaras:v4`) to check whether it contains "Hey Vaani".
Phrases without the wake word are discarded, but that audio still leaves your device and uses API credits.
Push-to-talk (hold F9) only sends audio while you hold the key. Turn the wake word off in `vaani setup` or with `VAANI_WAKE=0`.

## Safety

- The agent can call only a whitelisted set of tools. It never runs shell commands generated by the model.
- **SAFE_MODE** (on by default) asks you to confirm before Enter/send, delete, or purchase-like actions.
- The pyautogui **FAILSAFE** is on. Slam the mouse into any screen corner to abort automation at once.
- Tool errors are caught and spoken back to you. They never crash the loop.

## Configuration

Set these in `~/.vaani/.env` (written by `vaani setup`) or in your environment:

| Variable | Default | Purpose |
|---|---|---|
| `SARVAM_API_KEY` | (none) | Sarvam API subscription key |
| `VAANI_HOME` | `~/.vaani` | Config, models and temp directory |
| `VAANI_PTT_KEY` | `f9` | Push-to-talk key |
| `VAANI_WAKE` | `1` | `0` turns off the wake word (push-to-talk only) |
| `VAANI_WAKE_WORD` | `hey vaani` | Wake phrase |
| `VAANI_SAFE_MODE` | `1` | `0` skips the confirmation prompts |
| `VAANI_AGENT_MODEL` | `sarvam-105b` | Agent LLM |
| `VAANI_FALLBACK_MODEL` | `sarvam-105b` | Fallback agent LLM |
| `VAANI_VISION_MODEL` | `gemma4` | Screen-reading model |
| `VAANI_REASONING_EFFORT` | (unset) | Optional reasoning effort for the agent |
| `VAANI_STT_MODEL` / `VAANI_STT_TRANSLATE_MODEL` | `saaras:v4` | Speech-to-text |
| `VAANI_TRANSLATE_MODEL` | `mayura:v1` | Translation |
| `VAANI_TTS_MODEL` | `bulbul:v4-flash` | Text-to-speech |
| `VAANI_TTS_SPEAKER` | (per language) | Force one TTS voice |

## Troubleshooting

- **No mic input:** run `vaani doctor`. On **macOS**, give your terminal Microphone access (System Settings > Privacy & Security > Microphone).
  On **Windows**, turn on Settings > Privacy > Microphone > "Let desktop apps access your microphone".
- **Linux audio or automation errors:** `sudo apt install libportaudio2 python3-tk python3-dev scrot xclip`.
  pyautogui and pynput need an X11 session. On Wayland, log in with "Ubuntu on Xorg".
- **WSL:** audio needs WSLg (Windows 11) or a PulseAudio bridge, and laptop control only reaches the Linux side.
  To control Windows apps, run the native Windows install instead.
- **Typing or hotkeys do nothing (macOS):** add your terminal under Privacy & Security > **Accessibility** (and Input Monitoring for F9), then restart the terminal.
- **F9 conflicts with a media or function key:** set `VAANI_PTT_KEY` (for example `f8`), or press Fn+F9.
- **The wake word misfires or never triggers:** use F9, or set `VAANI_WAKE=0`. In noisy rooms the wake word sends more phrases to Sarvam (more credits); prefer F9 there.
- **401/403 from Sarvam:** your key is wrong or expired. Run `vaani setup` again.
